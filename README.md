# iRoof.top Homebrew tap

```sh
brew install irooftop/tap/rooftop            # the server (then: brew services start rooftop)
brew install --cask irooftop/tap/irooftop    # the desktop app (macOS)
```

`Formula/rooftop.rb` and `Casks/irooftop.rb` are updated automatically by the
[release workflow](https://github.com/irooftop/rooftop/blob/main/.github/workflows/homebrew.yml) of
[irooftop/rooftop](https://github.com/irooftop/rooftop) whenever a release is published.
